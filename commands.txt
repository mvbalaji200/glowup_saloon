4. **Prove Concurrency Guard & SMS Logging (GS-10 — Part 1):** Fires two identical bookings for 10:00 AM to trigger 201 Created followed by 409 Conflict.
Send the first booking request for tomorrow at `10:00:00`, immediately followed by a duplicate request for the exact same stylist and time:

```bash
php artisan tinker --execute="
\$time = now('Asia/Kolkata')->addDay()->format('Y-m-d 10:00:00');
\$payload = [
    'customer_phone' => '9876543210',
    'branch_id'      => 1,
    'service_id'     => 1,
    'stylist_id'     => 1,
    'starts_at'      => \$time,
];

\$req1 = Illuminate\Http\Request::create('/api/bookings', 'POST', [], [], [], ['CONTENT_TYPE' => 'application/json', 'HTTP_ACCEPT' => 'application/json'], json_encode(\$payload));
\$res1 = app()->handle(\$req1);
echo '1st Booking Status: ' . \$res1->getStatusCode() . PHP_EOL;

\$req2 = Illuminate\Http\Request::create('/api/bookings', 'POST', [], [], [], ['CONTENT_TYPE' => 'application/json', 'HTTP_ACCEPT' => 'application/json'], json_encode(\$payload));
\$res2 = app()->handle(\$req2);
echo '2nd Booking Status (Duplicate): ' . \$res2->getStatusCode() . PHP_EOL;
echo '2nd Booking Response: ' . \$res2->getContent() . PHP_EOL;
"

```

Show the interviewer that the `10:00:00` slot is now gone from `/api/slots` and that the confirmation SMS was logged in `sms_logs`:

5. **Cancel the Booking & Prove the Slot Frees Up (GS-10 — Part 2):** Updates booking status to cancelled without deleting the database row.
Cancel booking `1` and re-query `/api/slots` to prove `10:00:00` returns to the available pool:

```bash
php artisan tinker --execute="
\$reqCancel = Illuminate\Http\Request::create('/api/bookings/1/cancel', 'POST');
\$resCancel = app()->handle(\$reqCancel);
echo 'Cancel Status: ' . \$resCancel->getStatusCode() . PHP_EOL;
echo 'Booking Status in DB: ' . DB::table('bookings')->where('id', 1)->value('status') . PHP_EOL;

\$tomorrow = now('Asia/Kolkata')->addDay()->toDateString();
\$reqSlots = Illuminate\Http\Request::create('/api/slots?branch_id=1&service_id=1&date=' . \$tomorrow, 'GET');
\$resSlots = app()->handle(\$reqSlots);
echo 'Is 10:00:00 available again? ' . (str_contains(\$resSlots->getContent(), '10:00:00') ? 'YES (Freed)' : 'NO') . PHP_EOL;
"

```
